## 4. DECISIONS
- **Portable runtime model** (user-approved): read-only seed inside `_internal/` (templates/static/scripture JSONs at exact on-tree positions so `Path(__file__).parent/"data"` still resolves; `seed/db.sqlite3` + `seed/media` snapshots taken at build time) + writable runtime next to the exe (`data/proclaim.sqlite3`, `data/hymns/`, `media/`). Seed copied **only on first launch, never overwrites**. Rebuilding the app re-snapshots the current `db.sqlite3`, so new songs are picked up automatically.
- `DEBUG=True` + `ALLOWED_HOSTS=["*"]` in the packaged app (LAN trust boundary; `static()`/`staticfiles_urlpatterns()` media/static serving depends on DEBUG).
- Daphne started programmatically via `daphne.cli.CommandLineInterface().run([...])` — NOT `twistd` (avoids Twisted plugin discovery); `run` is an instance method (real bug found & fixed).
- **autobahn nvx disabled** (spec excludes + `AUTOBAHN_USE_NVX=0` env in portable.py): its CFFI modules compile `autobahn/nvx/*.c` at import time, PyInstaller ships no `.c` and there is **no autobahn hook** (verified absent in PyInstaller core and hooks-contrib), so it must be excluded to force the bundled pure-Python UTF-8 validator.
- `"churchcast.asgi"` added to `hiddenimports`: PyInstaller's bundled `hook-django.py` only auto-adds `<pkg>.wsgi`, and the ASGI app is passed to Daphne BY NAME as a string (`"churchcast.asgi:application"`), invisible to static analysis — without it, launch dies with `ModuleNotFoundError: No module named 'churchcast.asgi'`.
- Seed filename: spec bundles `db.sqlite3 → seed/` (keeps source name) while runtime wants `data/proclaim.sqlite3`; `seed_runtime` accepts either `seed/proclaim.sqlite3` or `seed/db.sqlite3` — prevents silent empty-DB fresh installs (0 songs / 1 room, observed).
- The 16 "Hidden import not found" warnings are **expected/harmless**: generated by upstream `hook-django.py` probing `<app>.templatetags` / `<app>.context_processors` for every `INSTALLED_APPS` entry (verified daphne/channels/staticfiles/presentation have none), plus `pycparser.lextab/yacctab` (optional generated tables), `django.db.backends.oracle.compiler` (file doesn't exist; Oracle backend unused), and `channels.testing.*` (deliberately excluded). Build still exits 0.
- `console=True` (visible terminal required for banner/error box), `upx=False`, onedir (`exclude_binaries=True`), excludes `tkinter`/`numpy`/`matplotlib`. Branding renamed ChurchCast → **Proclaim** (exe/folder/banner); the `churchcast` module namespace kept (avoid risky renames mid-packaging).
